# Summary
A Software as a Service aimed at promoting data-informed decision-making in African education. In addition to 
providing the core services of a school management system, it leverages the power of machine learning to predict 
the future performance of teachers and students using behavioral, academic and demographic data collected over 
time. It also provides personalized, visual explanations of these predictions.

# Features
- Student performance prediction and explanations with advanced machine learning techniques
- Teacher performance prediction and explanations with advanced machine learning techniques
- School management
  - Attendance tracking.
  - Exam and test score upload.
  - Student information management.
  - Teacher information management.
